# ArchInstall TUI

Modular TUI application for ArchLinux installation using Python, Textual, and Rich.

## Features

- Modular architecture with decoupled layers
- Multi-language support (ES/EN)
- Standalone module execution
- Step-by-step installation guide

## Development

```bash
uv sync
uv run python -m archinstall_tui
```
